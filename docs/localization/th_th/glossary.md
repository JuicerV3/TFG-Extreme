# Thai Terminology

This glossary covers concepts, not canonical game-object names. Canonical
searchable names remain exact English and are listed in `pilot.json`.

| English concept | Thai | Usage |
|---|---|---|
| Ore Vein | สายแร่ | Geological deposit concept |
| Prospecting | การสำรวจหาแร่ | Activity/mechanic |
| Rock Knapping | การกะเทาะหิน | TFC shaping mechanic |
| Knapping | การกะเทาะ | Short contextual form |
| Casting | การหล่อ | Metal-processing concept |
| Alloy | โลหะผสม | Material concept |
| Forging | การตีขึ้นรูป | Anvil/metalworking concept |
| Hydration | ระดับน้ำในร่างกาย | Quest mechanic |
| Thirst | ความกระหายน้ำ | Player status |
| Body Temperature | อุณหภูมิร่างกาย | Player status |
| Insulation | ฉนวนกันความร้อน | Clothing/environment concept |
| Nutrition | โภชนาการ | Food mechanic |
| Contaminants | สารปนเปื้อน | Food mechanic |
| Voltage | แรงดันไฟฟ้า | Use with exact tiers/symbols |
| Current | กระแสไฟฟ้า | Electrical concept |
| Tier | เทียร์ | Keep LV/MV/etc. exact |
| Tick | ทิก | Game-time concept |
| Slot | สล็อต | Inventory/UI concept |
| Potable water | น้ำดื่มได้ | Drinkable-water concept |
| Saturation | ค่าความอิ่ม | Food mechanic |
| Alloying | การผสมโลหะ | Processing action |
| Shelf life | อายุการเก็บรักษา | Food preservation |
| Crushing damage | ความเสียหายประเภททุบ | TFC damage type |
| Piercing damage | ความเสียหายประเภทแทง | TFC damage type |

Do not mechanically rewrite ordinary prose to enforce this table. Context and
natural Thai take priority for ordinary grammar.
